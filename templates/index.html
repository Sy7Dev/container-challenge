UNDER THE HOOD

What's actually happening?

01

The browser makes a request

When you visit localhost:5003, the request is sent to the application.

02

Flask handles the request

Flask runs inside its own Docker container and decides what response should be returned.

03

Redis stores the counter

Visiting /count tells Flask to increment the visits value stored in Redis.

04

Docker Compose connects everything

Compose creates the network between the containers, allowing Flask to communicate with Redis using its service name.
